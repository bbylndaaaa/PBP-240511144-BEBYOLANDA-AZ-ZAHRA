Tentang Saya

Halo! Saya Bebyolanda Az Zahra, mahasiswa aktif semester 5 Program Studi Teknik Informatika di Universitas Muhammadiyah Cirebon. Saya memiliki ketertarikan besar pada dunia teknologi, khususnya di bidang pengembangan website, desain antarmuka pengguna (UI/UX), dan pengolahan data.

Pengalaman paling berharga saya dapatkan saat menjalani program magang di PT PLN (Persero) UP3 Cirebon pada Divisi Perencanaan. Selama magang, saya dipercaya membantu pengelolaan anggaran investasi, evaluasi kinerja korporat, perencanaan sistem kelistrikan pelanggan, serta membangun dashboard monitoring berbasis website (SKKI) untuk memudahkan pemantauan data manajemen secara interaktif dan efisien.

Selain kegiatan akademik, saya aktif berkontribusi dalam kepengurusan Himpunan Mahasiswa Teknik Informatika (HIMATIF) pada Departemen Bisnis dan Kemitraan. Saya adalah pribadi yang teliti, komunikatif, senang mempelajari hal baru, dan selalu bersemangat untuk berkolaborasi dalam menciptakan karya teknologi yang solutif.
